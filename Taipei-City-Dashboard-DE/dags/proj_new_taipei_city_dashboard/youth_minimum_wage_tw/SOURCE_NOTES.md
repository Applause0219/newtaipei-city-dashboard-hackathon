# youth_minimum_wage_tw 來源筆記

## 來源與範圍

- 勞動部「歷年基本工資調整」歷史頁與「歷年最低工資／基本工資調整」最新頁均為伺服器渲染 HTML；請以瀏覽器 User-Agent 抓取 `p`／`li` 段落。
- 歷史頁的資料從民國 45 年起，最新頁補上民國 113、114 年發布且分別自民國 114、115 年生效的最低工資。
- 未明示施行月日的早期段落保留民國年作為 `period_type=year`，不擅自補推月份；明示「自某日」才用 `effective_date`。
- 實跑輸出 57 列，涵蓋 1956-01-01 至 2026-01-01；月／時兩個指標的原始金額各自保留。

## 轉換與契約

- 原始金額不是契約允許的 `value_type`，因此輸出 `minimum_wage_monthly_index` 與 `minimum_wage_hourly_index`，以民國 110 年月 24,000 元、時 160 元為 100；原始新臺幣金額完整放在 `breakdown`。
- 這是全國、全性別、無年齡的勞動市場基準：`age_lower`、`age_upper`、`age_band_raw` 全為 `None`，18–35 判定為 `unavailable`。不能把基本工資當成青年實際薪資平均值。
- 每次執行會核對每個原始金額都有一列輸出，並分別核對月／時指數轉換後的輸入與輸出總和；另對相鄰調整點做三倍尺度防護。基本工資是長期上升序列，若用全歷史中位數會把合法趨勢誤判，因此防護以相鄰調整點為比較群組。`KNOWN_BAD_YEARS` 目前為空。
- 率或人口比例沒有用於此 DAG；沒有做 18–35 的比例縮放。

## 陷阱與未解決事項

- 舊頁與新頁有重疊內容，DAG 以期間去重；若同一期間的月／時金額不一致會直接拋錯。
- 目前是薪資基準指數，不是新北市資料，也不是「初任薪資」；初任薪資歷年查找結果另見 `INITIAL_SALARY_HISTORY_RESEARCH.md`。
