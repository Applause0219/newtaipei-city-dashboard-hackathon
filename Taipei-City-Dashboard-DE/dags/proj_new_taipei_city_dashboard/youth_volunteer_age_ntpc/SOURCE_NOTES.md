## 欄位對應

來源欄位**完全沒有語意**——`field1`、`percent2` … `percent17`。這正是命題所述
「格式不一：異質資料整合門檻高」的具體樣態，與 `employment_age_structure` 是同一種病。

對應取自資料集頁面的「主要欄位說明」，但該說明字串在 `percent15` 之後被截斷，
`percent16` / `percent17` 的語意無法從頁面得知。

**以算術反推確認**：若 `percent16/17` 為最後一個年齡組（65歲以上），
則各年齡組男性加總應等於 `percent4`（合計男）、女性加總應等於 `percent5`（合計女）。
以 2006 年為例：

```
男：7 + 63 + 228 + 892 + 1128 + 370 = 2688 = percent4  ✓
女：21 + 83 + 377 + 3400 + 4013 + 917 = 8811 = percent5  ✓
```

**19 個年度 × 男女 = 38 組對帳全數相符（38/38，0 不符）**，推論成立。

| 來源欄位 | 意義 | 契約欄位 |
|---|---|---|
| `field1` | 年 | `period_start` / `period_end` |
| `percent2` / `percent3` | 社區發展協會理事長人數 男/女 | `indicator_id=community_association_chair_count` |
| `percent4` / `percent5` | 志工人數合計 男/女 | `age_band_raw="合計"`，年齡欄位留空 |
| `percent6` / `percent7` | 未滿12歲 男/女 | `age_lower=NULL, age_upper=11` |
| `percent8` / `percent9` | 12-17歲 男/女 | `(12, 17)` |
| `percent10` / `percent11` | 18-29歲 男/女 | `(18, 29)` |
| `percent12` / `percent13` | 30-49歲 男/女 | `(30, 49)` |
| `percent14` / `percent15` | 50-64歲 男/女 | `(50, 64)` |
| `percent16` / `percent17` | 65歲以上 男/女（反推確認） | `(65, NULL)` |

對帳邏輯**保留在 DAG 內每次執行**。來源若改版導致欄位語意飄移，ETL 會直接拋錯而非默默寫入錯誤數字。

## 年齡粒度與 18–35 換算

- 來源分組：未滿12 / 12-17 / **18-29** / **30-49** / 50-64 / 65以上
- **可否換算至 18–35：`apportioned`**
  - 18-29 組完整落在 18–35 內 → 全取
  - 30-49 組跨越 35 的邊界 → 需以單齡人口做組內分攤（取 30–35，即該組的前 6 個年次）
  - 下界 18 恰好對齊組界，這點運氣不錯，只有上界要分攤
- 分攤基準由 `youth_pop_single_age` 提供，換算函式見 `db_migrations/20260905_youth_fact.sql`

## 時序深度

- 最早：2006 年；最新：2024 年，共 19 年
- 來源**每次回傳完整歷史序列**，不是當下快照 → `load_behavior: replace` 安全，不會遺失歷史

## 觀察

2024 年志工年齡結構（男女合計）：

| 年齡組 | 人數 |
|---|---|
| 未滿12歲 | 170 |
| 12-17歲 | 746 |
| **18-29歲** | **1,981** |
| 30-49歲 | 5,511 |
| 50-64歲 | 27,141 |
| 65歲以上 | 23,555 |
| 合計 | 59,104 |

18-29 歲僅佔全體志工 **3.4%**，而 50 歲以上合計佔 85.9%。
青年社會參與偏低是青年局的業務核心關切，這份資料有 19 年序列可以看趨勢，
是儀表板上值得放的一張圖。
