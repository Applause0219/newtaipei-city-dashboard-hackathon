# 新北市嬰兒出生數按生父年齡（ODRP064／ODRP065）

## 來源與年度探測

```text
ODRP064：https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP064/{民國年度}?PAGE={n}
ODRP065：https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP065/{民國年度}?PAGE={n}
```

兩個端點都以民國90至115實測探測，且每個請求帶瀏覽器 User-Agent。RIS 查無資料時是 HTTP 200 + `OD-0102-S`，不是404；DAG與verify以回應碼判斷。

| 資料集 | 實測有資料年度 | 單一年度全國列數／頁數 | 新北完整交叉表格數 |
|---|---|---:|---:|
| ODRP064（按登記日期） | 110、111、112、113 | 66,240（民國113為66,239）／34頁 | 5,220；民國113為5,219 |
| ODRP065（按發生日期） | 110、112、113、114 | 66,240（民國113為66,239）／34頁 | 5,220；民國113為5,219 |

ODRP065民國111是實測 `OD-0102-S` 的缺年，不補零。ODRP064民國114雖然HTTP 200，但回應是**非法截斷JSON**：`responseData`陣列尚未閉合便直接以 `}` 結束，只有1,261個部分紀錄且沒有有效分頁資訊；列入 `KNOWN_BAD_YEARS` 排除，不把半份資料當成完整年度。另實測 ODRP064 與 ODRP065 民國113 都少同一個新北交叉格：板橋、男嬰、生父未滿20歲、生母未滿15歲；兩者都以 `KNOWN_INCOMPLETE_PERIODS` 記錄，不補估、不補零。其餘年度每區都有2個嬰兒性別 × 10個生父年齡組 × 9個生母年齡組。

## 欄位改版與資料模型

英文年度使用 `statistic_yyy / according / district_code / site_id / sex / father_age / mother_age / birth_count`。民國113改成中文；ODRP064的代碼欄為 `行政區域代碼`，ODRP065為 `區域別代碼`，另有 `區域別`、`嬰兒性別`、`生父年齡`、`生母年齡`、`嬰兒出生數`。DAG以角色別名統一，找不到唯一角色直接失敗。

交叉表的年齡標籤實測為：

- 生父：`未滿20歲`、`20～24歲`、`25～29歲`、`30～34歲`、`35～39歲`、`40～44歲`、`45～49歲`、`50～54歲`、`55～59歲`、`60歲以上`。
- 生母：`未滿15歲`、`15～19歲`、`20～24歲`、`25～29歲`、`30～34歲`、`35～39歲`、`40～44歲`、`45～49歲`、`50歲以上`。

這些不是標籤字串塞進年齡欄；生父主體的整數界限存於 `age_lower/age_upper`，原始標籤另存 `age_band_raw`。生父年齡是事實表的年齡主體，因此 `gender=male`；來源的 `sex` 是嬰兒性別，放在 `breakdown.baby_gender`，生母年齡也放在 `breakdown`。

## 對帳與零值

每個資料集／年度先把新北實際交叉表的出生數加總為 `input_total`，再以 `_area_code、according、baby_gender、father_age、mother_age` 分組。分組前所有必要維度先清理及填補空值，空維度直接失敗；`output_total` 必須在濾零前與 `input_total` 相等。交叉表格數也必須完整，唯一允許的缺格是上段記錄的民國113那一格。通過後才移除零值，並在 `reconciliations` 記錄 `emitted_rows`、`emitted_rows_nonzero`、`dropped_zero_rows`。全期為0的年齡／性別／行政區格會消失，需在查詢端補維度格時自行補零。

每個資料集另做3倍尺度防護，以各年度新北出生數總量和其餘年度中位數比較；目前沒有未知尺度異常。ODRP064民國114是資料格式異常而非數值異常，已用明確清單排除並保留理由；其餘新異常直接 `raise`。

## 18–35 判定

生父年齡有 `未滿20歲` 與 `35～39歲` 兩個邊界組，故18–35只能判定 **`apportioned`（行為計數、低信心）**；20–24、25–29、30–34是完全落在範圍內的原始子組。**本DAG不把18–35分攤結果固化，也不把率概念套到出生計數**；查詢階段才決定是否用均勻或其他可審計方法分攤。依專案既有實測，人口分攤誤差約0.08%，行為計數（出生）約3%，本資料的「生父18–35」應採後者的保守解讀。

## 目前限制

這支同時保留登記與發生兩種口徑，必須在下游以 `breakdown.source_dataset`／`count_basis` 分開比較，不可混加。ODRP064民國114的來源仍未修復；若日後官方修正，需先移除已知壞期並重新驗證，而不是自行修補截斷JSON。
