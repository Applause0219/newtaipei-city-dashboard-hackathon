# 新北市性侵害通報案件被害者（按年齡別、性別）

## 來源驗證

- 資料頁：https://data.ntpc.gov.tw/datasets/fe5a68d6-1313-4695-bf51-30bc0940196d
- API：https://data.ntpc.gov.tw/api/datasets/fe5a68d6-1313-4695-bf51-30bc0940196d/json?page={0-based}&size=5000
- 驗證日期：2026-09-06；資料頁 HTTP 200、JSON API HTTP 200；請求帶瀏覽器 User-Agent。
- 實際抓到 19 列，涵蓋 2006–2024 共 19 年，單頁已包含全部資料。
- 提供機關：新北市政府主計處；資料集頁標示更新頻率為每年。

## 主要欄位說明（資料集頁原文對應）

`field1(年)`、`percent2(性侵害通報案件被害者人數_總計男)`、
`percent3(性侵害通報案件被害者人數_總計女)`；
`percent4/5(0_5歲男/女)`、`percent6/7(6_11歲男/女)`、
`percent8/9(12_17歲男/女)`、`percent10/11(18_23歲男/女)`、
`percent12/13(24_29歲男/女)`、`percent14/15(30_39歲男/女)`、
`percent16/17(40_49歲男/女)`、`percent18/19(50_64歲男/女)`、
`percent20/21(65歲以上男/女)`、`percent22/23(年齡不詳男/女)`。

程式接受 `percentN` 與 `percent N` 別名；缺欄位或別名衝突會拋錯。

## 年齡與 18–35 判定

18–23、24–29 完整落在命題的 18–35 歲區間；30–39 跨過 35。因此整支資料判定為 **apportioned**，不是 exact。DAG 保留來源的原始年齡組，不自行把 30–39 拆成 30–35，也不把分攤後的數字寫回來源事實層；查詢層若採均勻假設，必須另外標示假設。

`年齡不詳` 是來源明示的已知 sentinel，不是無法解析的未知標籤：`age_lower/age_upper=None`、`age_band_raw="年齡不詳"`。若出現其他無法解析標籤會直接 raise。

## 合計列、對帳與尺度防護

- `sexual_assault_victim_total_count` 是來源的全齡男／女合計；`sexual_assault_victim_age_count` 是各年齡組明細。兩種 indicator 分開，避免把總計和分項重複相加。
- 每次執行都驗證 19 年 ×（2 個全齡欄 + 10 組年齡 × 2 性別）來源 cell 全部且只輸出一次；再驗證各年度明細男、女加總分別等於來源全齡男、女合計。任何不符直接 raise。
- 每年度全齡總數與其餘年度中位數比較，超過 3 倍直接 raise，防止來源範圍突然改變而畫出假尖峰。
- `value_type=count`、單位「人」。這不是 rate，不做依人口比例縮放。

## 輸出語意與觀察

- `gender` 與 `age` 都指被害者本人；`area_code=65000`、`area_level=city` 為新北市全市。
- 全齡合計沒有年齡欄位，三個 age 欄位均為 `None`，並以 separate indicator 保存；不推估其年齡。
- 2006–2024 的全齡通報被害者合計由 953 人升至 1,703 人，中間年度有明顯波動；青年數字不能直接把全齡合計當成 18–35。
