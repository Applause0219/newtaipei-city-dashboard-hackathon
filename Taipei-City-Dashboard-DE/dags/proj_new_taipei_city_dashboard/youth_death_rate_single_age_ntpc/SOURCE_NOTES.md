# 新北市人口死亡率（ODRP117，按性別及單一年齡）

## 來源驗證與年度邊界

```text
https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP117/{民國年度}?PAGE={n}
```

實測民國90至115：民國113、114回 `OD-0101-S`；民國90至112及115、116回 HTTP 200 + `OD-0102-S`。民國114第1頁回傳3頁、全國4,444列，新北市202列；民國113全國4,443列，新北市201列。新北市資料的來源行政區代碼是 `65000000`，事實表契約依既有 DAG 統一成全市 `65000`、`area_level=city`。

RIS 的查無資料不是404，DAG與獨立 verify 都以 `responseCode` 判斷；請求使用瀏覽器 User-Agent。民國113欄名為中文（`統計年`、`縣市別`、`歲數`、`死亡率`），民國114改為英文（`statistical_year`、`county`、`age`、`death_rates`），以角色別名正規化。

## 年齡與性別

每年預期為101個年齡格 × 2性別。0至99是單一年齡，直接存 `(n,n)`；來源最後的 `歲數=100` 是101個年齡類別的開放尾端，依死亡率表的語意存 `(100,NULL)`，並在 `age_band_raw` 保留原始字串 `100`、在 `breakdown` 說明 `100歲以上`。性別代碼 `1/男` 對應 `male`，`2/女` 對應 `female`；年齡與性別都是死亡者本人。

民國113實測只有201格，缺 **男、0歲** 一格；民國114為完整202格。這是來源缺格，不補造零值；民國113其餘201格照原值輸出，每列 `breakdown` 標示 `source_incomplete` 與缺格。若未來出現不同缺格，DAG直接失敗。本次實跑以 API 當前回應為準；先前探測筆記把缺格記成男、100歲以上，已由這次逐格檢核更正。

## 單位、對帳與尺度防護

`death_rates` 實測如新北0歲約5.16、100歲以上約376，採 `value_type=rate`、`unit=‰（每千人）`。每個來源格逐一與輸出格對帳，不把死亡率相加；年度尺度防護取新北所有性別／年齡率的中位數，任一年度與其餘年度中位數相差超過3倍就 `raise`。目前沒有已知壞年度，`KNOWN_BAD_YEARS={}`。

## 18–35 判定

**`exact`。** 18至35歲每一歲都有原始死亡率格，可直接篩選 `age_lower >= 18 AND age_upper <= 35`。但 **率永遠不可相加**，所以本DAG只輸出各單齡率；下游若要18–35綜合率，必須取得同口徑分母後在查詢階段加權，不能把18個率加總或平均冒充綜合率。

## 未解決事項

民國113缺男0歲格的來源原因尚未由戶政司另行說明；本DAG不推估。資料目前只有民國113–114兩個年度，適合做最新單齡率截面與兩年比較，不宜宣稱長期趨勢。
