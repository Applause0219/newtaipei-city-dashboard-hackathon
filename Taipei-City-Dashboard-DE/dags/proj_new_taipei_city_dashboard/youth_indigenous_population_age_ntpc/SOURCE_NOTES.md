# 新北市原住民人口（單齡年齡）

## 來源驗證

```
https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP015/{民國年月}?PAGE={n}&COUNTY=新北市
```

- 平台：內政部戶政司 RIS OpenData，免驗證；程式請求一律帶瀏覽器 User-Agent。
- 已實測民國 11412：帶 `COUNTY=新北市` 時 `responseCode=OD-0101-S`、`totalPage=315`、每頁 2,000 列。
- ODRP015 是**年月**端點，不是年度端點。DAG 每個民國年取最後一個有資料的月份；完整年度優先取 12 月，尚未結束的民國 115 取實測最後可用的 11507。
- 實作會從民國 114 向前、向後探測，連續兩個無資料年度才停止；查無資料是 HTTP 200 + `OD-0102-S`，不能用 HTTP 狀態碼判斷。
- 原始資料是村里級交叉表，欄位為 `statistic_yyymm / district_code / site_id / village / sex / indigenous_registered / age / indigenous_count`。`age` 是單齡（含 `100歲以上`），`indigenous_registered` 實測為山地原住民、平地原住民、平埔原住民。
- 跨年度欄名不固定：民國 107、108 的統計年度欄帶 BOM，民國 107–113 使用 `aborigine_registered`／`aborigine_count`，114–11507 才使用 `indigenous_registered`／`indigenous_count`。DAG 以角色別名正規化，找不到角色欄位就失敗，不能寫死最新年度欄名。

## 轉換與契約

- 每頁抓到後立即以 `district_code[:8]` 篩選既有 29 個新北行政區；非新北列不進記憶體中的聚合器。為應付數千頁的大型端點，頁面以小批次 bounded concurrency 抓取，但每個 response 完成後立即篩選／聚合，不累積全國資料。村里資料只聚合為行政區列，另產生 `65000` 全市列，沒有把村里粒度寫入事實表。
- 年齡只依原始標籤解析為整數區間：單齡 `n歲 -> (n,n)`；開放區間保留 `None` 端；無法解析直接 `raise`，不靜默略過。
- `gender` 是原始人口性別（男／女）；另產生 `total` 合計列。`value_type=count`、`unit=人`。
- 18–35 判定為 **`exact`**：下游直接篩 `18 <= age_lower` 且 `age_upper <= 35`，DAG 不把 18–35 分攤結果固化，保留所有原始單齡列。
- `breakdown` 保留原住民身分、來源月份、村里聚合來源與行政區名稱。行政區代碼與 `youth_pop_single_age` 完全一致，可直接 join。

## 必做防護與對帳

- 每一頁只保留新北資料，並在每個來源期別核對：輸入新北資料總數 = 行政區男女輸出總數 = 行政區 `gender=total` 總數 = 全市 `gender=total` 總數；不符直接失敗。
- 分組前沒有把空值靜默轉成遺失類別；未知性別、未知原住民身分、未知行政區代碼、未知年齡標籤都直接失敗。數字解析會去除千分位逗號。
- 每次執行以每期新北原住民人口總數和其餘期別中位數做 3 倍尺度檢核。未知範圍變更直接 `raise`；目前沒有已確認的壞年度，`KNOWN_BAD_YEARS={}`。

## 觀察與限制

- 輸出列數會因「行政區 × 單齡 × 性別 × 原住民身分」交叉表而多於來源的概念指標數；這是聚合後仍保留零值年齡／分類格的來源結構，不是重複計算。村里原始資料可取得，但刻意不輸出村里粒度以免事實表膨脹。
- 這是**原住民現住人口**，不是原住民教育、原住民族別或原住民事件計數。18–35 的分子與 `youth_pop_single_age` 同期總人口比較時，分母是全體新北 18–35 歲人口，因此得到的是原住民人口占比，不是原住民內部比例。
- 本來源無需分攤，也沒有把「身分」當成年齡；`exact` 僅因來源真的有單齡 `age` 欄位。

## 未解決事項

- ODRP015 為月快照，年度序列的完整性取決於 RIS 未來是否補發／保留各月；DAG 會重新探測，不寫死年度清單。
- 本次未將原住民族別細分納入，因 ODRP015 的欄位是原住民登記身分；若要民族別需另用沒有年齡欄位的資料集，不能混入本 DAG。

## 表大小：濾除零值列

來源是 **村里 x 單齡 x 性別 x 原住民身分別** 的完整交叉表，
聚合到行政區後仍有大量零值組合。處理方式與
`youth_naturalized_population_age_ntpc`、`youth_marriage_age_ntpc` 一致：
**在逐期對帳通過之後才濾除 `value = 0` 的列**，
所以對帳驗證的是未刪減的完整集合，且 0 對數值總和沒有貢獻。

`reconciliations` 記錄 `emitted_rows` 與 `emitted_rows_nonzero`，
讓丟棄量可追蹤，而不是靜默行為。

實測：

```
全表列數    181,800  ->  97,664   （縮 1.9 倍，約 46% 是零值）
```

九期的 `input_total` 在濾零前後**逐一完全相同**
（55,607 / 56,592 / 57,407 / 57,717 / 57,906 / 58,372 / 61,777 / 64,708 / 66,139），
18-35 歲比例也分毫不差。

縮減幅度明顯小於 `youth_naturalized_population_age_ntpc`（12 倍），
因為原住民在新北市每期有 5.6-6.6 萬人，交叉表大部分格子填得滿；
定居人口每年只有四千人，同樣的格子絕大多數是空的。

注意：「平埔原住民」是較晚出現的類別，且在新北市 18-35 歲區間
民國 114、115 年皆為 0，濾零後該類別的列會消失。
這是預期行為；需要顯式零的視覺化應在查詢端 `LEFT JOIN` 維度表補零。

## 觀察到的趨勢

18-35 歲原住民佔同齡總人口比例（分母取 `youth_pop_single_age`）
**九年連續上升**：

```
2018  1.849%      2023  2.015%
2019  1.893%      2024  2.117%
2020  1.945%      2025  2.218%
2021  1.990%      2026  2.276%
2022  2.007%
```

分子從 18,084 增至 18,940（+4.7%），分母從 977,889 降至 832,214（-14.9%）——
比例上升主要來自青年總人口萎縮，而非原住民青年大量增加。
這個區分在做視覺化敘事時必須講清楚，否則容易誤讀。
