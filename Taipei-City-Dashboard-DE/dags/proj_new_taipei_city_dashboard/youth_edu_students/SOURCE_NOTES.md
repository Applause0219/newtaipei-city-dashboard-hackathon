# 大專校院在學學生數（新北市）

## 來源驗證

```text
https://stats.moe.gov.tw/files/detail/{學年度}/{學年度}_student.csv
```

- 平台：教育部統計處檔案下載，免驗證，檔案為 UTF-8 BOM CSV。
- 驗證器實際探測 103–115 學年度：103–113 均 HTTP 200；114、115 均 HTTP 404，
  因此目前可用範圍是 103–113。DAG 從 103 往後探測，連續兩個 404 才停止，未把終點寫死。
- 這是**在學學生數**，不是 `youth_edu_graduates` 的畢業生數。每列是學校、等級別、
  日間∕進修別、體系別與縣市的學生統計。
- 本次驗證轉換 **1,205 個新北市來源列、3,615 個事實列**（每個來源列 male、female、total
  各一列），涵蓋 103–113 學年度，即西元 2014-08-01 至 2025-07-31。

## 跨年度欄位與學生數語意

欄位依角色比對，不寫死年度欄名：

- 103–106 沒有 `總計`、`男生計`、`女生計`，只有一年級至七年級及延修生的男女欄；
  男、女各自加總後得到該校／學制／班別的學生數。這四年中 `-` 表示 0。
- 107–112 有 `總計`、`男生計`、`女生計` 與年級／延修生男女明細。
- 113 的明細另有 `華語先修生男`、`華語先修生女`，也納入性別明細對帳。
- 有合計欄的年度，DAG 驗證合計欄與明細欄相等；所有年度都驗證男＋女＝總計。
- CSV 使用正規 parser 讀取，數值解析會去除千分位逗號；空白或其他無法解析的數值直接拋錯。

## 縣市與學年度

來源縣市名稱帶改制前舊碼，例如 `01 新北市`；臺中、臺南、高雄各可能有兩個舊碼。
一律先去代碼、再依名稱對應標準代碼，避免依舊碼分組拆開直轄市。新北市輸出
`area_code=65000`、`area_level=city`，可與既有青年 DAG join。

這份檔案的學年度就是在學期間，不像畢業生檔案需要減一年：

```text
學年度 y：period_start = (y + 1911)-08-01
          period_end   = (y + 1912)-07-31
          period_type  = academic_year
```

## 年齡與 18–35 判定

來源沒有學生個人年齡欄，只有學制、年級、延修生與日間∕進修別。
因此 `age_lower`、`age_upper`、`age_band_raw` **全部為 None**，並在本來源標示
18–35 = **`unavailable`**。不能由「大學／碩士」、年級或身分別推估年齡；
也不能把學生數依人口比例縮放成 18–35，因為那會製造來源不存在的年齡分布。

## 對帳與未解決

- 每一學年度只對新北市來源列做輸出；輸出的 male、female、total 三種性別列數與合計，
  必須分別等於新北市輸入，否則 raise。對帳檢核留在 DAG 每次執行。
- 目前 114、115 學年度尚未上架；後續檔案出現時會由探測邏輯自動納入。
- 本 DAG 聚合到學校／等級別／日間進修別／體系別的男女總數，沒有另發年級指標；
  原始年級欄名與計數口徑保存在來源檔本身，`breakdown.student_count_basis` 記錄本列採來源合計或明細加總。
