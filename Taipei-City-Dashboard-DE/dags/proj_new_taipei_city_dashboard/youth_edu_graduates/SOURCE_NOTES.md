# 大專校院校別畢業生數

## 來源驗證

```
https://stats.moe.gov.tw/files/detail/{學年度}/{學年度}_graduate.csv
```

- 平台：教育部統計處 檔案下載。免驗證，`Content-Type: application/octet-stream`，UTF-8 with BOM
- 驗證時間：2026-09-05
- **實測 103～114 學年度共 12 個檔案全部回 200**，每檔約 52～57KB、711～858 列
- 同路徑另有 `{y}_student.csv`（92KB，學生數）與 `{y}_teacher.csv`（35KB，教師數），
  皆回 200，可作為後續 DAG 的來源
- `{y}_graduate_dept.csv`、`{y}_student_dept.csv`、`{y}_school.csv`、`{y}_gender.csv` 皆 404

轉換後產出 **28,238 列**，涵蓋 **102～113 畢業學年度（西元 2013～2025）**、21 個縣市。

## 這份資料的三個陷阱

### 一、欄位名在 12 個年度內改過三次

同一個機關、同一張表：

| 變異 | 出現年度 |
|---|---|
| `日間_進修別`（底線） → `日間∕進修別`（全形除號 U+2215） | 107 學年度起改用除號 |
| `上學年畢業生男` / `上學年畢業生女` → `男生` / `女生` | **僅 110、111 兩年** |
| `學年度` 欄位存在與否 | 103-106、108、110、111 **沒有這欄** |

所以 ETL **依角色比對欄位**（找含「男」「女」「日間」的欄位）而非寫死名稱，
找不到就拋錯。若寫死 `上學年畢業生男`，110 和 111 兩年會靜默產出空資料。

這是命題所述「格式不一：異質資料整合門檻高」最乾淨的實例——
異質不只發生在不同機關之間，同一機關同一張表跨年度就已經不一致了。

### 二、縣市用的是改制前舊碼，直轄市同名不同碼

來源縣市欄位是「舊碼 + 現行名稱」，合併升格的直轄市各出現兩次：

```
06 臺中市  /  19 臺中市     （原臺中縣 / 原臺中市）
11 臺南市  /  21 臺南市     （原臺南縣 / 原臺南市）
12 高雄市  /  50 高雄市     （原高雄縣 / 原高雄市）
01 新北市                   （原臺北縣）
30 臺北市
```

**依代碼分組會把三個直轄市各拆成兩半。** 所以一律以**名稱**對應到標準行政區代碼
（新北市 → `65000`）。原始縣市名保留在 `breakdown.county`。

### 三、「上學年畢業生」——檔案學年度不等於畢業學年度

欄位名是「**上學年**畢業生男/女」：113 學年度的調查記錄的是 112 學年度畢業的人。

因此 `period` 依**畢業學年度**設定（檔案學年度 − 1）：

```
113 學年度檔案 → 畢業學年度 112 → period_start 2023-08-01, period_end 2024-07-31
```

檔案學年度另存 `breakdown.source_academic_year`，這個判讀若有異議可以回溯修正。

已交叉驗證：校別檔（本 DAG 來源）與含科系的明細檔，同一學年度同一校同一學制的數字完全相同
（政大 D日 B學士：111 年 829/1281、112 年 889/1209、113 年 823/1268、114 年 867/1275）。

## 其他處理

- **代碼前綴剝除**：`B 學士` 與 `B學士` 並存，不正規化會被當成兩個等級別。
  剝除規則要注意 `X4+X` 這種——只能剝一個字元，多剝會切成 `+X`
- **名稱本身也會漂移**：`C 二年制` 與 `C 二技` 是同一個學制的不同寫法。
  所以 `breakdown` 同時存 `level`（正規化名稱）與 `level_code`（代碼前綴）。
  **下游要分組時請用 `level_code`，它才是穩定的識別**
- **千分位逗號**：114 學年度檔案的數字含 `"1,275"` 這種帶引號逗號的值，
  必須用正規 CSV parser 並在轉數值時去除逗號
- **自動納入新年度**：ETL 從 103 往後探，連續兩次 404 才停，新學年度上架會自動被抓進來

## 年齡粒度與 18–35 換算

**`unavailable`。**

這份資料有學制（博士/碩士/學士/四技/二技/二專/五專）但**沒有任何年齡欄位**。
「學士約 18-22 歲」是推論不是事實——在職專班、二技、進修部的學生年齡分布與日間部完全不同，
而這份資料裡日間∕進修別有 5 種（日、進、職、修、暑）。

因此 `age_lower` / `age_upper` / `age_band_raw` **一律留空**，不做任何年齡推估。
學制放在 `breakdown.level`，需要時由查詢端自行決定要不要做假設，
但那個假設會是明示的，不會被醃進事實表裡。

## 觀察

新北市歷年畢業生總數（男女合計，依畢業學年度）：

| 畢業學年度 | 人數 |
|---|---|
| 2013 | 34,216 |
| 2016 | 35,252 |
| 2019 | 31,672 |
| 2022 | 30,190 |
| 2023 | 28,048 |
| **2024** | **26,698** |

自 2014 年高點 35,788 人降至 2024 年 26,698 人，**十年減少 25%**。
新北市有 25 所大專校院。這是缺工預測的供給端訊號，
也適合和初任薪資、行業別職缺放在同一張圖上做對照。
