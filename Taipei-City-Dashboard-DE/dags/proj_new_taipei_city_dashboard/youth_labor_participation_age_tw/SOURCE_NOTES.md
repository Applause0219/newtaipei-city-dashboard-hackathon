# 勞動力參與率（按年齡組別及性別）

## 來源驗證

- [資料集 31061：歷年15歲以上民間人口之年齡](https://data.gov.tw/dataset/31061)，頁面實際解析到 `mp04016.xml`，實跑 HTTP 200、`text/xml`。
- [資料集 31063：歷年勞動力之年齡](https://data.gov.tw/dataset/31063)，頁面實際解析到 `mp04018.xml`，實跑 HTTP 200、`text/xml`。
- 兩份 XML 都是 1978 起的年度平均加月資料；目前各有 72 筆，包含民國 114 年平均（西元 2025）及其後月資料。月列沒有重複寫西元年，解析器依「上一個年度平均的下一曆年」推導，不能把 2026 月份誤標成 2025。
- 資料單位是千人，來源是台灣全國，使用 `area_code=TW`、`area_level=country`。
- 實跑輸出 7,128 列（72 期 × 11 年齡組 × 3 性別 × 3 指標），涵蓋 1978-01-01 至 2026-12-31。

## 轉換與對帳

- 只選年齡原子組：15–19、20–24、25–29、30–34、35–39、40–44、45–49、50–54、55–59、60–64、65歲以上；欄位以中英文角色比對，不寫死年度欄名。無法解析或欄位數量不唯一直接 `raise`。
- 每一組輸出三個指標：民間人口 count、勞動力 count、勞參率 rate。rate 由同一期、同性別、同一年齡組的勞動力／民間人口計算；不是拿人口比例去縮放既有率。
- 來源兩邊的每個數值格都要產生一列，count 的輸入／輸出格數與 Decimal 總和不符直接失敗。每個年度的原子年齡總量另做三倍尺度防護；目前 `KNOWN_BAD_YEARS` 為空。

## 18–35 判定：`apportioned`

資料有可配對的分子／分母，所以不同於只有率的失業率來源，18–35 在查詢階段可以處理；但 15–19 與 35–39 都跨越命題邊界，且來源是五歲／開放組，不是 18–35 原生值。ETL 只保留原始組別，查詢時必須明確選擇組內分攤規則，再以分子與分母各自合併後計算率。**不可直接對各組 rate 做人口比例縮放，也不可在 ETL 固化 18–35 結果。**

## 觀察與限制

- 本支是全國勞動市場基準，不是新北市地方數字，不能套用 `65000` 或 29 區代碼。
- 人數以千人為單位且已四捨五入；由此計算的年齡組 rate 可能與主計總處另行發布的百分比欄有微小四捨五入差異。
- `ws.dgbas.gov.tw` 在本 runner 的憑證鏈不被預設 CA 信任；DAG 先正常 TLS，僅對該官方主機使用窄範圍未驗證 fallback。正式 Airflow 應把正確 CA 鏈加入 worker trust store 後移除 fallback。
