# 新增個人就學貸款月資料

## 來源驗證

- [聯徵中心官方 CSV](https://www.jcic.org.tw/jcweb/en/services/inquiry/public/files/Stut_New_Amt.CSV) 實測 HTTP 200、UTF-8 BOM；資料涵蓋 2012-01 至目前已發布月份。
- 欄位為年、月、新增個人學貸總人數、新增個人學貸總金額（仟元）、新增個人學貸平均金額（仟元），另有百分位數。
- DAG 輸出三個指標：人數 `count`、總金額 `sum`、平均金額 `mean`；總金額是加總量，不能標成平均數。

## 18–35 判定與限制

- `unavailable`。來源沒有年齡、性別或借款人居住地；不能把「學生」等同 18–35 歲，也不能把全國數字當成新北市數字。
- 學貸人次／人數是不同概念；本 CSV 的總人數與總金額不應拿來互相推導，平均金額僅保留來源值。
- 來源是曆月資料，不是學年度；不自行轉成學年度。

## 品質檢核

- 以欄位角色比對，不依賴欄位排列；數字解析會移除千分位逗號。
- 每一個月的三個數值欄都必須各產生一列，輸入數值格與輸出列數對帳。
- 跨年尺度檢核只使用完整曆年，排除最新未滿12個月的部分年度；超過其餘年度中位數 3 倍即失敗。
