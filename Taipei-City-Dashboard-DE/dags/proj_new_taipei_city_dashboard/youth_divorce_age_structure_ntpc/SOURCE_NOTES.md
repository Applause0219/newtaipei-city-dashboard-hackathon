# 新北市離婚人口年齡結構比

## 來源驗證

- 資料頁：<https://data.ntpc.gov.tw/datasets/f9618881-5cf2-4bcc-83b1-5021885dd4f3>
- API：<https://data.ntpc.gov.tw/api/datasets/f9618881-5cf2-4bcc-83b1-5021885dd4f3/json?page={page}&size=1000>
- 每個 HTTP 請求都帶瀏覽器 User-Agent；實測 page 0 回 19 列（2006–2024），page 1 回空陣列。
- 主要欄位說明確認 `field1` 是年；`percent2/3` 起依序是 15–19、20–24、25–29、30–34、35–39、40 歲以上的男性／女性結構比。
- API 欄位名稱雖為 `percent`，實測每個性別六欄直接加總為 100，已是百分點；DAG 不乘 100，直接以 `unit=%` 輸出。
- 實跑輸出 228 列：19 年 × 6 年齡組 × 2 性別，期間 2006–2024，`area_code=65000`。

## 年齡、性別與 value_type

- `value_type=rate`、`unit=%`；這是離婚人口內部的年齡結構比，不是 18–35 歲人口率。
- 年齡主體是離婚人口本身，故男性／女性和年齡主體一致。
- 標籤轉為整數區間：`15–19歲 → (15,19)`、`40歲以上 → (40,None)`；無法解析會 raise，沒有靜默略過。
- 18–35 判定為 **apportioned**：15–19 只有 18–19、35–39 只有 35 歲落在命題範圍。ETL 只保留原始年齡組，不按人口比例縮放，也不固化 18–35 結果；查詢層需另定分子／分母與分攤方法。

## 對帳與尺度防護

- 每年、每性別輸入六欄必須加總至 100（容許 0.05 個百分點誤差），輸出逐來源欄位對帳；不符直接 raise。
- `drop_scope_anomalies()` 以年度總量相對其餘年度中位數的 3 倍門檻防止最新年度尺度錯置；目前沒有已知壞年度，`KNOWN_BAD_YEARS={}`。
- 來源沒有民國年，也沒有區級資料；期間為西元曆年，統一輸出新北市全市。

## 未解決事項

- 來源是年齡結構比，無法從本表單獨得到精確 18–35 歲離婚人數或率；這不是 ETL 缺漏，避免把比例誤當計數。
