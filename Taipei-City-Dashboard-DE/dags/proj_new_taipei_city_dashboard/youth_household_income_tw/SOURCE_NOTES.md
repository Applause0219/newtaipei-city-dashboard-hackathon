# 家庭收支調查：經濟戶長年齡別所得與消費

## 來源驗證

- 目錄：[data.gov.tw 資料集 108265](https://data.gov.tw/dataset/108265)
- DAG 每次先讀目錄頁，再解析主計總處 CSV；不寫死資源 UUID。
- 實測 CSV HTTP 200，UTF-8，2024 年，6 個所得分位列（含全體家庭）。
- 來源欄位含全體家庭，以及經濟戶長「未滿30、30–34、35–39、40–44、45–54、55–64、65歲及以上」的所得／消費配對欄。

## 模型限制

- 年齡主體是「經濟戶長」，不是每一戶內的青年，也不是個人所得；經濟戶長定義與抽樣誤差見[主計總處家庭收支調查報告](https://ws.dgbas.gov.tw/001/Upload/463/relfile/11503/235296/113.pdf)。
- 全國資料沒有新北市地域切片；18–35 判定為 `apportioned`（僅查詢層）：未滿30含未滿18，35–39跨過35，不能在 ETL 產生精確18–35值。
- 所得與消費是平均數，`value_type=mean`；兩者差額／儲蓄率若要呈現，必須在查詢層標成 `derived`，本 DAG 不新增導出指標。
- 這支目前是資料集提供的最新快照（2024），不是自行回補的歷年序列；官方報告後續曾修訂，年度更新須重新抓取與比對。

## 品質檢核

- 欄位以角色辨識，找不到唯一欄位即失敗；數值解析會移除千分位逗號。
- 每個來源數值格都必須對應一列輸出，並檢查輸入／輸出格數一致。
- 有跨期資料時啟用每指標 3 倍尺度防護；單期快照會明確略過跨期比較，不會製造假警報。
