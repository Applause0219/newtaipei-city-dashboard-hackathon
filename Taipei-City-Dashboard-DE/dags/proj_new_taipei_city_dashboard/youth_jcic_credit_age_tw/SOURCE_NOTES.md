# 聯徵中心按年齡與性別的信用統計

## 來源驗證

- [聯徵中心官方 CSV NPL_1_63](https://www.jcic.org.tw/jcweb/en/services/inquiry/public/files/NPL_1_63.csv) 實測 HTTP 200、UTF-8 BOM。
- 來源欄位：年、月、性別、年齡、授信類別、人數、額度、件數、平均每筆額度、餘額、逾期放款比率；實測期別自 2021-12 起。
- 輸出區分人數／件數 `count`、額度／餘額 `sum`、平均每筆額度 `mean` 與逾期放款比率 `rate`。額度與餘額單位依聯徵統計定義為千元；比率保留來源小數比例，不乘人口數。

## 年齡與母體限制

- 年齡組依來源原樣解析，例如 `20歲以下`→`(None,20)`、`20-45`→`(20,45)`、`45歲以上`→`(45,None)`；`其他` 不猜測上下界。
- 18–35 判定為 `apportioned`／部分 `unavailable`：來源缺 18–19 的獨立組別，且 30–45（或 20–45）跨過35；DAG 只落原始組，不在 ETL 固化分攤。
- 這是聯徵涵蓋的信用存量，不是完整家庭負債、資產或信用評分；`stock_flow=stock` 保存在 `breakdown`。
- 年齡主體是借款人，性別代碼 1／2 轉成 male／female；不可解讀為新北市數字，因為來源是全國。

## 品質檢核

- 以欄位角色比對；未知年齡標籤、性別代碼或數值格式直接失敗，不靜默丟列。
- `-` 僅代表該來源指標缺值，該指標不輸出；其餘每一個有效數值格必須對應一列，並做輸入／輸出對帳。
- 每年取最後月份做跨年尺度檢核；若指標總量與其他年度中位數相差超過 3 倍即失敗。
